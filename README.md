# TFM2 드래프트 추천기 (밴픽 오버레이)

**Teamfight Manager 2** 밴픽 화면에 떠서, **내 세이브의 현재 패치 실제 통계**로 "지금 뭘 픽/밴하면 좋은지"를 보여주는 오버레이입니다. 게임은 전혀 안 바꿉니다(읽기 전용).

> 직접 드래프트하면서 메타 데이터를 보고 싶은 사람을 위한 도구예요. "수석코치 위임"(AI 자동 드래프트)을 대체하는 게 아니라, **직접 뽑되 정보를 보고 뽑게** 돕습니다.

---

## 뭘 보여주나요?
- **라인별 추천 픽/밴** — 현재 패치 승률 기반 점수 + 티어(S~D)
- **챔프 역할**(힐/탱/브/딜) — 실제 딜·탱·힐 데이터로 자동 분류
- **시너지·카운터·역할 조합** 참고
- **60챔프 그리드에 티어 표시** → 한눈에 메타 티어표
- **피어리스 / 하드 피어리스** 다전제 룰 지원

## 왜 쓰나요? (검증)
게임 데이터로 객관적으로 확인한 결과:

- **게임의 드래프트(AI 포함)는 실제 승률을 거의 안 따라갑니다.** 밴율과 실제 승률의 상관 = **+0.19** (거의 무관). 즉 "센 챔프"와 "많이 밴/픽되는 챔프"가 따로 놉니다.
  - 예: 승률 1위 챔프가 픽률 24%로 저평가 / 승률 평범한 챔프가 평판으로 58% 밴.
- **이 도구가 보여주는 승률 신호는 검증됨** — 드래프트만으로 승자를 **62.7%** 맞힘 (찍기 = 52%).

→ 즉 **현장이 놓치는 "실제로 이기는 픽"을 이 도구가 알려줍니다.**

## 수석코치 위임이랑 뭐가 달라요?

| | 수석코치 위임 | 이 도구 |
|---|:---:|:---:|
| 누가 드래프트 | AI 자동 | **내가 직접** |
| 내 선수 숙련 고려 | O | X |
| 현 패치 메타(승률·티어) 표시 | X (블랙박스) | **O** |
| 내 판단(상대·전략) 반영 | X | **O** |
| 노력 | 0 | 클릭 |

둘은 다른 용도예요. *귀찮으면 위임, 직접 + 메타 보고 싶으면 이 도구.*

## 설치
1. 이 저장소를 받아서 (Code → Download ZIP) 압축 해제
2. **`install.bat` 더블클릭** — 오버레이는 `%LOCALAPPDATA%\tfm2-overlay`에, 모드는 게임 `mods\` 폴더에 자동 설치
   - 게임을 기본 Steam 경로에 안 깔았으면, `release\mod\tfm2_db_export` 폴더를 직접 `(게임폴더)\mods\` 에 복사
3. **게임 실행 → Mods 메뉴에서 "TFM2 추천기 통계 추출기" 켜기 → 게임 재시작**

## 사용법
1. 세이브 로드 → 인게임 진입하면 **오버레이가 자동 실행**됩니다 (모드가 통계를 읽고 런처를 띄움)
2. 밴픽 화면에서:
   - **단계**(밴/픽) 선택 → 그 단계의 추천이 뜸
   - 진행되는 밴/픽을 **클릭으로 표시** → 추천 실시간 갱신
3. **Ctrl+F10** 으로 오버레이 켜기/끄기
4. 챔프 찾기: **초성 버튼**(ㄱㄴㄷ…) 또는 영문 검색

## 솔직한 한계
- **새 게임/판수 적으면 추천이 약합니다** — 통계가 쌓여야 정확. (표본 적은 챔프엔 `?`)
- **시너지·카운터는 표본이 꽤 쌓여야** 정확합니다. 가장 믿을 신호는 **승률·티어·역할**.
- **라이브 자동 읽기는 안 됩니다**(게임이 막아둠) → 밴픽을 **수동 클릭**으로 표시.
- **내 선수 숙련은 반영 못 함** (글로벌 승률 기준). 그건 위임 코치의 강점.

## 버전 / 호환
- **게임 버전 0.4.7 용**입니다. 게임이 업데이트되면 모드(코드 모드)는 재빌드가 필요할 수 있어요.

## 빌드 (개발자용)
- **오버레이/런처/도구** (`src/draft-overlay`, `src/draft-weights-gen`): 일반 Rust. `cargo build --release`
- **모드** (`src/tfm2_db_export`): TFM2 Mod SDK 0.4.7 필요. `rust-toolchain.toml`의 nightly로 SDK 빌드 스크립트 사용. (자세한 건 [TFM2 Mod 문서](https://github.com/teamsamoyed/TeamfightManager2Mod) 참고)
- 데이터 위치: `%LOCALAPPDATA%\tfm2-overlay\` (모드·런처·오버레이 공용)

읽기 전용이고 안티치트 없는 싱글 게임용입니다. 문제/제안은 Issues로.
